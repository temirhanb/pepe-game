# Об игре:
```
Вы играете за лягушонка Пепе, который старается оправиться после ссоры с Жаб Жабычем.

Данные хранятся в localstorage.
Есть магазин за алмазы, где можно купить "донатные" баффы.
z.ai отвечал за кор проекта. Чучуть gemini для поиска косяков. Доводил визуал, хранение данных и правки ручками.
```
